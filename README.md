# PlayPass

PlayPass — сервис записи и оплаты тренировок, где оплата = подтверждение участия.

## Apps
- `apps/web` — frontend на Next.js
- `apps/api` — backend на NestJS

## Packages
- `packages/types` — общие типы
- `packages/config` — общие конфиги
- `packages/ui` — общие UI-компоненты

## Запуск
Инструкция будет добавлена после инициализации приложений.
